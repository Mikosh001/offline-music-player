# SAZ — сенің әуенің

Қазақша интерфейсі бар музыка каталогы және жеке офлайн кітапхана. HTML, CSS және JavaScript негізіндегі PWA; қолданбаны іске қосу үшін құрастыру қадамы немесе API кілті қажет емес.

## Іске қосу

Node.js 20 немесе жаңарақ нұсқамен:

```sh
npm start
```

Браузерде `http://127.0.0.1:4173` ашыңыз. Портты `PORT` орта айнымалысымен өзгертуге болады. Файлдарды `file://` арқылы ашу PWA мен дерекқорды дұрыс тексеруге жарамайды.

GitHub Pages үшін `main` бранчының түбірін жариялаңыз. Барлық файлдар салыстырмалы жолдарды қолданады; `/offline-music-player/` ішкі жолында да жұмыс істейді. Телефонда орнату және офлайн режим үшін HTTPS қолданыңыз.

- 12 орындаушының ресми каталогынан жиналған 267 ән метадерегі. Бұл — 2026-10-05 күні жасалған іріктеу; толық дискография деген кепілдік берілмейді.
- Ернар Амандық, Moldanazar, Sadraddin, Мирас Жүгінісов, Тұрар, Думан Марат.
- Ұқсас көңіл күйдегі Darkhan Juzz, Ayau, Dequine, Kalifarniya, Қазыбек Құрайыш және Bakr.
- Лирика, инди, қазақ поп, R&B / соул, акустика, ырғақты және электро сүзгілері.
- «Жүрекке жақын», «Түнгі қала», «Жол үстінде», «Жаңа толқын» жинақтары. Бұл стильдер — ресми жанр белгілері емес, редакциялық көңіл күй іріктеуі.
- Қазақша және латынша орындаушы атауларымен іздеу, сұрыптау, ұнаған әндер.
- Жеке плейлист жасау, атауын өзгерту, ән қосу/алып тастау, өшіру.
- Ойнату кезегі, кезекті өзгерту, келесі әнге қосу, қайталамай араластыру, repeat off/all/one.
- Ән мен ойнату орнын, дыбыс деңгейін және режимдерді сақтау. Қайта ашқанда музыка өздігінен басталмайды.
- Ұйқы таймері, пернетақтада Space, / және бағыттау пернелері, Media Session басқаруы.
- Толық файлды жүктеу, барысын көрсету, тоқтату, қайталау, топтап жүктеу.
- Жергілікті аудио импорттау, сүйреп тастау, бірдей файлды қайта қосуды анықтау.
- Толық аудиосы бар `.saz` сақтық көшірмесі және қайта қалпына келтіру.
- Бұрынғы IndexedDB v1 кітапханасын v2-ге атомдық көшіру.

## Әндер мен толық аудио

Аталған орындаушылардың **толық коммерциялық аудиофайлдары бұл репозиторийге енгізілмеген**. Каталогта тек ресми атаулар, ұзақтық және Apple Music сілтемелері бар. Ресми Apple Music плеері онлайн ашылады; үзінді не толық ойнату сервис пен аккаунттың қолжетімділігіне байланысты. Оның аудиосы көшірілмейді және кэштелмейді.

Офлайн жүйесін бірден сынау үшін «Баптаулар → Аспаптық демоны тыңдау» немесе «Жүктелгендер → Жүктеуді сынау» бөлігін ашыңыз. SAZ үшін синтезделген 2 түпнұсқа аспаптық демо CC0-1.0 бойынша берілген. Оларды `scripts/generate-demo.mjs` қайта жасайды; олар ешбір орындаушының әні немесе дыбысы емес.

### Жеке құрылғыда файлды байланыстыру

Әннің жанындағы қалта белгісін не «… → Аудиофайлды байланыстыру» басыңыз. Таңдалған файл сол әнге байланыстырылып, IndexedDB-де сақталады. Файл серверге жіберілмейді. Жалпы «Ән қосу» батырмасы өз файлдарыңыздан бөлек жеке кітапхана жасайды.

### Пайдаланушыларға жүктететін толық аудионы қосу

Рұқсат етілген аудионың HTTPS мекенжайын «… → Толық аудио сілтемесін қосу» арқылы енгізіңіз. Одан кейін «Баптаулар → Каталогты сақтау» басып, экспортталған `catalog.json` файлын сайттағы файлдың орнына қойыңыз. Басқару өзгерістері бастапқыда тек сол браузерде сақталады; сайттың серверіне автоматты түрде жарияланбайды.

Каталог жазбасының негізгі өрістері:

```json
{
  "id": "stable-song-id",
  "title": "Ән атауы",
  "artistId": "ernar",
  "artist": "Ернар Амандық",
  "styles": ["lyrical"],
  "audioUrl": "https://your-storage.example/music/song.mp3",
  "downloadable": true,
  "license": "Автордың тарату рұқсаты",
  "mime": "audio/mpeg",
  "size": 7340032,
  "version": "1"
}
```

`id` тұрақты болуы керек. `size` — нақты файлдың байт саны; белгісіз болса 0 қойыңыз. Басқа домендегі қойма CORS арқылы қолданбаға файлды алуға рұқсат беруі керек. `audioUrl`, `license` және `downloadable: true` бірге болғанда ғана жүктеу ашылады. Бір аудиофайлдың шегі 150 МБ.

Тікелей аудио бар әнді онлайн тыңдауға болады; жүктелген көшірме бар болса, ол интернет бар кезде де жергілікті файлдан ойналады. «Офлайн дайын» тек жүктеу толық аяқталып, файл браузерде танылып, IndexedDB транзакциясы сәтті бекітілгенде көрсетіледі.

## Сақтау және офлайн режим

Service Worker тек қолданба файлдары мен каталогты сақтайды. Әндер бөлек IndexedDB `audio` қоймасында, метадеректер `library` қоймасында сақталады. Аудио Service Worker арқылы екінші рет кэштелмейді. Офлайн кезекте тек құрылғыдағы файлдар ойналады.

Жүктелгендер әр браузер мен әр құрылғыда бөлек. Браузердің деректерін тазалау әндерді өшіреді; квота мен автоматты тазалау ережелері браузерге байланысты. Тұрақты сақтау рұқсатын сұрау және `.saz` көшірмесін сақтау баптауларда бар. Квота — құрылғыдағы нақты бос орын емес.

Бұл PWA-да жүктеулер қолданба ашық тұрған кезде орындалады. Қолданба жабылғанда немесе құрылғы оны тоқтатқанда жүктеудің жалғасуына кепілдік жоқ. Таймер келесі JS орындалғанда мерзімді тексереді. Media Session мен экран құлыпталғандағы ойнатуды нақты iPhone/Android құрылғысында қосымша тексеру қажет.

Жаңарту дайын болса, «Жаңарту» жолағын басыңыз. Жаңа қолданба нұсқасы сақталған аудионы өшірмейді. Бұрынғы v1 қолданбасын жаңартқанда ескі қойма жаңа транзакцияға толық көшіріледі; көшіру сәтсіз болса, транзакция кері қайтарылады.

## Каталогты жаңарту

```sh
npm run refresh:catalog
```

Ресми iTunes Search API арқылы тек ән метадеректері жаңартылады. Орындаушы ID-лері `scripts/artists.mjs` ішінде бекітілген; Думан Мараттың ID-сі аттас басқа орындаушылардан бөлек. Бұл пәрмен аудионы жүктемейді. Тұрақты ән ID-леріне байланыстырылған аудиосілтемелер, рұқсат белгілері және жеке каталог жазбалары сақталады. Барлық жауаптар алынғаннан кейін ғана каталог файлы ауыстырылады.

Дереккөздер: [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html), [ресми Apple Music ендірілетін плеері](https://artists.apple.com/support/1117-apple-music-marketing-tools). Әр әннің жеке ресми сілтемесі `catalog.json` ішінде.

## Тексеру

```sh
npm test
```

Браузер тексерістері үшін алдымен `npm start` қосып қойыңыз, одан кейін бөлек терминалда:

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

Тексерістер каталогты, іздеуді, файл байттарын, нақты ойнатуды, офлайн қайта ашуды, тоқтаған секундты, плейлисттерді, сақтық көшірме мен толық аудионы қалпына келтіруді, импорт көшірмелерін, v1 көшіруді, үзіліп қалған жүктеуді, қате аудионы және 320–1440 px орналасуды қамтиды. Скриншоттар мен сынақ көшірмесі `test-results/` ішінде жасалады. Playwright Chromium іске қосылмаса, сол тесттер орнатылған Edge браузерін қолдануға тырысады.

| Файл                      | Мақсаты                                         |
| ------------------------- | ----------------------------------------------- |
| `index.html`, `style.css` | Қазақша responsive интерфейс                    |

| `core.js`                 | Іздеу, каталог тексеру, кезек және форматтау    |

| `service-worker.js`       | Қолданба мен каталогтың офлайн ашылуы           |
| `scripts/`                | Жергілікті сервер, каталог және демо жасау      |
| `tests/`                  | Негізгі логика және браузер тексерістері        |
