# SAZ — сенің әуенің

Қазақша интерфейсі бар музыка каталогы және жеке офлайн кітапхана. HTML, CSS және JavaScript негізіндегі PWA; қолданбаны іске қосу үшін құрастыру қадамы немесе API кілті қажет емес.

## Іске қосу

Node.js 20 немесе жаңарақ нұсқамен:

```sh
npm start
```

Браузерде `http://127.0.0.1:4173` ашыңыз. Портты `PORT` орта айнымалысымен өзгертуге болады. Файлдарды `file://` арқылы ашу PWA мен дерекқорды дұрыс тексеруге жарамайды.

GitHub Pages үшін сайт нұсқасы бар бранчтың түбірін жариялаңыз. Осы нұсқа `feat/qazaq-wave` бранчында; жариялау көзі сол бранчтың `/` түбірі болады. Барлық файлдар салыстырмалы жолдарды қолданады; `/offline-music-player/` ішкі жолында да жұмыс істейді. Телефонда орнату және офлайн режим үшін HTTPS қолданыңыз.

## Әндер мен толық аудио

Каталогтағы 207 әннің **203 жазбасына толық аудио қосылған**. Олардың негізі — сайт иесі ұсынған ZIP және SAZ-20261005-001 жеке рұқсаттар туралы мәлімдемесі. Әндер сайттың өз қоймасынан ойналып, «Офлайнға сақтау» арқылы браузерге сақталады. Қайталанған екі каталог жазбасы ортақ файлды қолданады: 202 бірегей MP3, шамамен 919 МБ. Хостинг көлеміне сыйдыру үшін толық ұзақтық сақталып, 192 кбит/с MP3 көшірмелері дайындалды; бастапқы ZIP өзгертілген жоқ.

Архивте төрт әннің файлы жоқ: Sadraddin — «18 лет (Acoustic version)», «Зажигалка»; Мирас — «Сенемін»; Duman — «Воспоминания». Олар «Аудио күтілуде» күйінде қалады.

Рұқсаттың жария негізі — [жинақтаушының мәлімдемесі](permissions/music-sources-and-permissions.html). Жеке Instagram хаттары ұсынылмаған және тәуелсіз тексерілген жоқ; ашық құжат нақты жеке келісім шарттарын өздігінен бекітпейді. SAZ-20261005-001 және F001–F203 — ішкі есепке алу нөмірлері, құқық иесі берген лицензия нөмірлері емес. Дереккөз сайттарының келісімдері SAZ рұқсаты ретінде қолданылмайды. Бастапқы құжаттар өзгеріссіз `permissions/` ішінде сақталған.

`permissions/hosted-audio-map.json` бастапқы ZIP хэштерін дайын MP3 хэштерімен және каталог ID-лерімен байланыстырады. 13 файлдың алынған парағы белгісіз; олардың ресми каталог сілтемесі жүктеу дереккөзі ретінде расталмаған. Мирас — «Қызғанамын» берілген жазбасының ұзақтығы каталогтағы метадеректен өзгеше; сайтта файлдың нақты ұзақтығы көрсетіледі.

Офлайн жүйесін бірден сынау үшін «Баптаулар → Аспаптық демоны тыңдау» немесе «Жүктелгендер → Жүктеуді сынау» бөлігін ашыңыз. SAZ үшін синтезделген 2 түпнұсқа аспаптық демо CC0-1.0 бойынша берілген. ### Сайтта сақтау және интернетсіз тыңдау

Әннің негізгі файлы сайттың `assets/audio/licensed/` қоймасында тұрады. Интернет бар кезде осы файл сайттың өз плеерінде ойналады. Пайдаланушы «Офлайнға сақтау» басқанда толық көшірме IndexedDB арқылы осы сайттың браузердегі сақтау орнына жазылады. Телефонның «Файлдар» немесе Downloads қалтасына MP3 жүктелмейді.

Серверде ғана тұрған файлды интернетсіз алу мүмкін емес. Интернет өшкенде алдын ала сақталған аудио ойналады; каталог, іздеу және плейлисттер де браузерде сақталып, ашылады. Әр құрылғының офлайн көшірмесі бөлек; браузер деректерін тазалау оны өшіреді. Офлайн көшірмені өшіру сайттағы негізгі файлды өшірмейді.

### Рұқсат алынған толық файлдарды сайт қоймасына қосу

`audio-manifest.example.json` файлын көшіріп, әр ән үшін каталогтағы тұрақты `trackId`, жергілікті `file`, `license`, рұқсат құжатын анықтайтын `permissionRef` және ресми `sourceUrl` толтырыңыз. `redistributionAllowed: true` тек қайта таратуға нақты рұқсат алынған соң қойылады. Ашық лицензия болса, `licenseUrl` да көрсетіңіз. Жеке келісімнің құжатын жалпыға жариялаудың қажеті жоқ; оның сілтеме-нөмірін тіркеңіз.

Алдымен файлдарды өзгертпей тексеру:

```sh
npm run publish:audio -- audio-manifest.json
```

Рұқсаты мен файлдары дайын жазбаларды сайт қоймасына көшіру:

```sh
npm run publish:audio -- audio-manifest.json --apply
```

Құрал барлық жазбаларды алдымен тексереді. Содан кейін аудионың дәл байттарын сайт қоймасына көшіріп, `catalog.json` ішіне салыстырмалы аудиожолды, көлемін, MIME түрін, SHA-256 хэшін және рұқсат деректерін байланыстырады. Файл форматының бастапқы белгісі тексеріледі; браузер офлайн сақтау кезінде аудионы нақты тануын қосымша тексереді. Бір файлдың шегі 150 МБ. Құрал құқық иесінің келісімін өзі алмайды және берілген рұқсаттың шынайылығын автоматты түрде растамайды.

Бірдей байттары бар аудио бірнеше каталог жазбасында кездессе, құрал ортақ файл мен бір аудиожолды қолданады. Әр жазбаның тұрақты ID-і және жеке рұқсат деректері сақталады.

Осыдан кейін жаңартылған жобаны хостингке жариялаңыз. `--apply` жергілікті сайт қоймасын өзгертеді; өздігінен GitHub-қа push жасамайды. Аудио нұсқасы кейін өзгерсе, бұрынғы офлайн көшірмені өшіріп, жаңа файлды қайта сақтаңыз.

### Жеке құрылғыда файлды байланыстыру

Әннің жанындағы қалта белгісін не «… → Аудиофайлды байланыстыру» басыңыз. Таңдалған файл сол әнге байланыстырылып, IndexedDB-де сақталады. Файл серверге жіберілмейді. Жалпы «Ән қосу» батырмасы өз файлдарыңыздан бөлек жеке кітапхана жасайды.

### Пайдаланушыларға жүктететін толық аудионы қосу

Рұқсат етілген аудионың HTTPS мекенжайын «… → Толық аудио сілтемесін қосу» арқылы енгізіңіз. Одан кейін «Баптаулар → Каталогты сақтау» басып, экспортталған `catalog.json` файлын сайттағы файлдың орнына қойыңыз. Басқару өзгерістері бастапқыда тек сол браузерде сақталады; сайттың серверіне автоматты түрде жарияланбайды.

Каталог жазбасының негізгі өрістері:

```json
{
  "id": "stable-song-id",
  "title": "Ән атауы",
  "artistId": "ernar",
  "artist": "Ернар Амандық",
  "styles": ["lyrical"],
  "audioUrl": "https://your-storage.example/music/song.mp3",
  "downloadable": true,
  "license": "Автордың тарату рұқсаты",
  "mime": "audio/mpeg",
  "size": 7340032,
  "version": "1"
}
```

`id` тұрақты болуы керек. `size` — нақты файлдың байт саны; белгісіз болса 0 қойыңыз. Басқа домендегі қойма CORS арқылы қолданбаға файлды алуға рұқсат беруі керек. `audioUrl`, `license` және `downloadable: true` бірге болғанда ғана жүктеу ашылады. Бір аудиофайлдың шегі 150 МБ.

Тікелей аудио бар әнді онлайн тыңдауға болады; жүктелген көшірме бар болса, ол интернет бар кезде де жергілікті файлдан ойналады. «Офлайн дайын» тек жүктеу толық аяқталып, файл браузерде танылып, IndexedDB транзакциясы сәтті бекітілгенде көрсетіледі.

## Сақтау және офлайн режим

Service Worker тек қолданба файлдары мен каталогты сақтайды. Әндер бөлек IndexedDB `audio` қоймасында, метадеректер `library` қоймасында сақталады. Аудио Service Worker арқылы екінші рет кэштелмейді. Офлайн кезекте тек құрылғыдағы файлдар ойналады.

Жүктелгендер әр браузер мен әр құрылғыда бөлек. Браузердің деректерін тазалау әндерді өшіреді; квота мен автоматты тазалау ережелері браузерге байланысты. Тұрақты сақтау рұқсатын сұрау және `.saz` көшірмесін сақтау баптауларда бар. Квота — құрылғыдағы нақты бос орын емес.

Бұл PWA-да жүктеулер қолданба ашық тұрған кезде орындалады. Қолданба жабылғанда немесе құрылғы оны тоқтатқанда жүктеудің жалғасуына кепілдік жоқ. Таймер келесі JS орындалғанда мерзімді тексереді. Media Session мен экран құлыпталғандағы ойнатуды нақты iPhone/Android құрылғысында қосымша тексеру қажет.

Телефондағы жоғарғы мәзір статус жолағы мен Dynamic Island үшін `safe-area` орын қалдырады; төменгі мәзір Home индикаторын жауып тұрмайды. Плеерде араластыру, алдыңғы ән, ойнату/кідірту, келесі ән және қайталау батырмалары әрқашан көрінеді. Ән атауын басқанда уақытын ауыстыру, таңдаулылар, кезек пен таймері бар толық плеер ашылады. Көлденең экранға бөлек ықшам орналасу бар; іздеу өрісінің 16 px қарпі Safari-дегі фокус масштабтауын болдырмайды.

Басты беттегі «Араластырып тыңдау» барлық қолжетімді негізгі әннен кезек құрады; каталог пен орындаушыдағы батырма сол бөлімдегі таңдауды араластырады. Офлайнда құрылғыда сақталған әндер ғана кіреді. Әр ID бір айналымда бір рет ойналады; араластыруды өшіргенде бастапқы кезек қалпына келеді. Media Session `previoustrack` / `nexttrack` әрекеттерін тіркейді, ал 10 секундтық `seekbackward` / `seekforward` әрекеттерін қоспайды. Құлып экранындағы батырмалардың түрін операциялық жүйе таңдайды.

Жаңарту дайын болса, «Жаңарту» жолағын басыңыз. Жаңа қолданба нұсқасы сақталған аудионы өшірмейді. Бұрынғы v1 қолданбасын жаңартқанда ескі қойма жаңа транзакцияға толық көшіріледі; көшіру сәтсіз болса, транзакция кері қайтарылады.

Сайт ашылғанда жария каталог интернеттен жаңартылады. Бұрын импортталған жеке каталог жаңа жария әндерді жасыра алмайды: жеке қосымша әндер және арнайы белгіленген аудиосілтемелер сақталады. Офлайнда соңғы жария каталог қолданылады; интернет қайта қосылғанда ол жаңартылады. «Баптаулар → Сайт каталогын жаңарту» деректерді өшірмей каталогты қайта жүктейді. Жеке жүктелген файлдар, таңдаулылар, плейлисттер және тыңдау орны бөлек қоймаларда сақталады.

## Каталогты жаңарту

```sh
npm run refresh:catalog
```

Ресми iTunes Search API арқылы тек ән метадеректері жаңартылады. Орындаушы ID-лері `scripts/artists.mjs` ішінде бекітілген; Думан Мараттың ID-сі аттас басқа орындаушылардан бөлек. Бұл пәрмен аудионы жүктемейді. Тұрақты ән ID-леріне байланыстырылған аудиосілтемелер, рұқсат белгілері және жеке каталог жазбалары сақталады. Барлық жауаптар алынғаннан кейін ғана каталог файлы ауыстырылады.

Метадерек көзі: [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html). Әр әннің жеке ресми сілтемесі `catalog.json` ішінде; ол толық аудионы қайта тарату лицензиясын бермейді.

## Тексеру

```sh
npm test
```

Браузер тексерістері үшін алдымен `npm start` қосып қойыңыз, одан кейін бөлек терминалда:

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

`tests/mobile-player.cjs` 44 px басқаруды, қауіпсіз аймақтарды модельдеуді, 203 әнді араластыруды, бастапқы кезекті қалпына келтіруді, толық плеер мен офлайн екі әндік кезекті тексереді. Қосымша WebKit тексеруі: `npx playwright install webkit`, кейін `SAZ_TEST_ENGINE=webkit node tests/mobile-player.cjs` (Windows PowerShell-де айнымалыны `$env:SAZ_TEST_ENGINE='webkit'` арқылы орнатыңыз). Windows WebKit онлайн MP3-ті ойнатқанымен, сынақ ортасында Blob аудиосын декодтау сәтсіз болды. Осы ортадағы орналасу мен онлайн басқаруды бөлек тексеру үшін `$env:SAZ_SKIP_OFFLINE='1'` орнатыңыз; офлайн сценарийдің өткізіп жіберілгені нәтижеде ашық көрсетіледі. Chromium/Edge офлайн сценарийінде сайттағы нақты толық MP3 файлдары қолданылады. Бұл компьютердегі WebKit сынағы нақты iPhone құрылғысын алмастырмайды.

Тексерістер каталогты, іздеуді, файл байттарын, нақты ойнатуды, офлайн қайта ашуды, тоқтаған секундты, плейлисттерді, сақтық көшірме мен толық аудионы қалпына келтіруді, импорт көшірмелерін, v1 көшіруді, үзіліп қалған жүктеуді, қате аудионы және 320–1440 px орналасуды қамтиды. Жариялау құралында алдымен барлық файлды тексеру, рұқсат белгісі жоқ жазбаны қабылдамау, өзгеріссіз preview және нақты байттарды сайт қоймасына көшіру тексеріледі. Браузер сынағы негізгі сайттан ойнатуды, MP3 жүктеу оқиғасын ашпай браузерде сақтауды және сыртқы музыка плееріне сұрау жіберілмеуін тексереді. Сынақ аудиолары оқшауланған тест контекстінде ғана қолданылады; коммерциялық әндердің аудиосы ретінде жарияланбайды. Скриншоттар мен сынақ көшірмесі `test-results/` ішінде жасалады. Playwright Chromium іске қосылмаса, сол тесттер орнатылған Edge браузерін қолдануға тырысады.

## Файлдар

| Файл                          | Мақсаты                                           |
| ----------------------------- | ------------------------------------------------- |
| `index.html`, `style.css`     | Қазақша responsive интерфейс                      |
| `script.js`                   | Каталог, жүктеулер, плеер, плейлисттер, көшірме   |
| `core.js`                     | Іздеу, каталог тексеру, кезек және форматтау      |
| `db.js`                       | IndexedDB сақтау және v1 → v2 көшіру              |
| `catalog.json`                | Ресми ән метадеректері және демолар               |
| `service-worker.js`           | Қолданба мен каталогтың офлайн ашылуы             |
| `scripts/`                    | Жергілікті сервер, каталог және демо жасау        |
| `scripts/publish-audio.mjs`   | Рұқсат алынған аудионы сайт қоймасына орналастыру |
| `audio-manifest.example.json` | Аудионы жариялау тізімінің толтырылмаған мысалы   |
| `tests/`                      | Негізгі логика және браузер тексерістері          |
